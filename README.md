# Super Ed

Tonic Trouble modernization for Linux (Armbian on ARM boxes) and modern PCs. Early days: nothing playable yet.

Bring your own game files. This repo will never contain Ubisoft assets or executables.

## Dev box setup

`armbox-ssh-key.txt` adds the dev machine's SSH public key to the ARM box. Run it on the box as your normal user:

    bash armbox-ssh-key.txt
